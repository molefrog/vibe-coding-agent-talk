# Design Guidelines — Slides

## Inspiration
- Teenage Engineering / KO synthesizer aesthetic
- USGC (US Graphics Company) — creators of Berkeley Mono
- Retro-futurism, console-style, terminal aesthetic
- Timeless and unfashionable — ignore design trends

## Design Philosophy (USGC)
- Emergent over prescribed aesthetics
- Expose state and inner workings
- Dense, not sparse
- Explicit is better than implicit
- Engineered for human vision and perception
- Performance *is* design
- Verbosity over opacity
- Flat, not hierarchical
- Don't infantilize users

## General
- Dark theme (dark background, light text)
- Technical, minimalist look
- Large font sizes for screen/projection

## Typography
- Primary font: Berkeley Mono (monospace)
- UPPERCASE headers with generous letter-spacing (0.1em–0.2em)
- Headers: font-medium or font-semibold (not bold with letter-spacing)
- Use `text-pretty` for better text wrapping

## Color Palette
- Background:       #191717  (--color-bg)
- Dark gray:        #313131  (--color-dark-gray)
- Gray:             #B8B7B5  (--color-gray)
- Off-white:        #F6F8F7  (--color-light)
- Orange (accent):  #EC5C2A  (--color-orange)
- Pale blue (rare): #D6E4EA  (--color-blue)

## Layout

### Content Slides (default)
- Centered container (max-w-3xl or max-w-4xl)
- Vertically centered: flex items-center justify-center h-full
- Comfortable padding (p-16 on container)

### Fullscreen Slides
- Edge-to-edge, no container
- For full-bleed images or special layouts

## Cards
- Light background (bg-light), dark text (text-bg)
- Padding: more vertical than horizontal (px-5 py-7)
- Number labels: text-base font-semibold text-orange
- Titles: text-xl font-semibold uppercase tracking-[0.08em]
- Description: text-lg text-dark-gray text-pretty

## Grids
- Use CSS Grid for multi-element layouts
- Equal height rows: grid-rows-2 (or auto-rows-fr)
- Cards fill cells: h-full on card elements
- Generous gap: gap-4 or gap-6

## Tables
- Subtle borders BETWEEN cells only
- No outer border
- Use --color-gray with low opacity

## Utility Components (src/components/)

### Highlight
Wrapper that animates opacity based on active state. Grid-friendly.

```tsx
import { Highlight } from "../components";

<Highlight active={step >= 1} className="h-full">
  <Card />
</Highlight>
```

Props:
- `active?: boolean` — default true
- `activeOpacity?: number` — default 1
- `inactiveOpacity?: number` — default 0.25
- `className` and all div props pass through

Uses snappy spring: stiffness 500, damping 30

## Stepped Slides (fragments)
URL format: `/3` (single step), `/3-1`, `/3-2` (multiple steps)

```tsx
// Define a stepped slide component
const MySlide = ({ step }: { step: number }) => (
  <div>
    <h1>Title</h1>
    {step >= 1 && <Card1 />}
    {step >= 2 && <Card2 />}
  </div>
);

// Export with steps count
export const slides = [
  "Simple slide",
  { component: MySlide, steps: 2 },
  <RegularJsxSlide />,
];
```

Navigation: Arrow right = next step → next slide, Arrow left = prev step → prev slide

## Animations (Motion)
- Use `motion` package for React: `import { motion } from "motion/react"`
- Prefer spring-based animations for natural feel
- On-mount: slide up with stagger (delay: i * 0.1)
- Spring config: stiffness 300, damping 20-25 for bounce
- Variants pattern for staggered animations:
  ```
  const variants = {
    hidden: { opacity: 0, y: 40 },
    visible: (i) => ({
      opacity: 1, y: 0,
      transition: { delay: i * 0.1, type: "spring", stiffness: 300, damping: 20 }
    })
  }
  ```
- Use layout animations sparingly

## Code Style
- NO inline styles (style={{ }})
- Use Tailwind classes only
- Custom colors via @theme in CSS
- Arbitrary values when needed: tracking-[0.1em]

## Notes
- Orange is the primary accent color
- Pale blue used very sparingly
- Grayscale for hierarchy
